# v1.2：备份、样本与复查

日期：2026-11-02。此版本落实实用功能规划的第一批，保持 Element 风格和现有检测流程。

## 使用方法

1. 工作台加载示例或上传图片，展开「样本信息」，填写编号、作物、地块、巡检批次和采集时间。编号自动生成且可修改；采集时间默认是录入时间，可按实际修改，与检测时间独立保存。
2. 保存检测结果后，在记录页用关键词或「更多筛选」查找样本。支持地块、批次、采集日期、检测来源、人工查看状态及复查任务状态的组合筛选。未填写采集日期的旧记录按检测日期筛选。
3. 在详情里勾选「安排复查」，填写原因、日期和可选处理说明。状态为待复查、已完成或已取消，可关联后续检测记录。已有任务通过“已取消”保留安排信息；“已人工查看”不会自动完成任务。
4. 工作台显示待复查、今日及逾期数量；记录页提供快捷筛选。日期按本机时区计算，在页面打开时定期更新，不会在关闭浏览器后推送通知。
5. 点击「导出全部备份」保存所有记录，包含样本、复核、复查任务和检测结果。到新设备点击「导入备份」，预览后确认合并；也兼容旧版单条 JSON 报告。

## 数据保护

- 仍保留 30 条上限，但不再自动覆盖。满额时保留当前检测结果供导出，新增和超额导入均停止；更新已有记录不受影响。
- 导入最多 5 MB、1000 条待校验记录。重复项跳过，坏记录单独标记，同 ID 不同内容默认保留原记录；展开差异对照后可逐条选择覆盖。
- 超出容量或保存失败时不部分写入、不删除旧记录。导入前后的变化会检查；导出文件不包含原图或模型权重。
- 删除记录会说明其复查安排及被关联情况；关联 ID 保留，缺失记录会显示提示。
- 关闭、按 Esc、切换路由或离开页面时，对尚未保存的详情编辑提示确认。存储失败保留输入，错误显示在当前弹窗内。
- 旧记录自动补充空样本字段，不虚构采集时间或复查任务。没有账户系统或自动云同步。

## 验证

18 项前端逻辑测试、6 项后端接口测试、生产构建；专项浏览器流程与旧流程回归。

新增可重复运行脚本：`tests/browser/practical-workflow.js`。在项目根目录启动 4176 端口的生产预览后，使用 Playwright CLI 的 `run-code --filename tests/browser/practical-workflow.js` 执行。脚本使用本地测试记录并清理该测试地址的历史，不用于存放正式记录的浏览器。旧回归脚本 `tests/browser/record-workflow.js` 还需要 5176 端口开发服务。

重点覆盖：备份完整性、空库恢复、旧单条报告导入、重复与冲突、无效来源/日期、满额不覆盖、字段更新不重复保存、任务与已查看状态独立、组合筛选、保存失败保留输入，以及 360–2560px 响应式布局。成功模型响应使用明确模拟，不代表模型精度验证。

尚未实现的后续项：逐框复核、图片持久化及对比、批量推理、打印报告。在线演示仍使用预设标注；真实检测需本地服务与授权模型。
