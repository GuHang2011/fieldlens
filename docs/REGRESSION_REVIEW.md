# 第二轮使用流程测试与修复

日期：2026-11-01。修复前基线：`7b65f4c`。

本轮重点检查跨页面操作、复核数据一致性、导出内容和键盘操作。以下 5 项均在浏览器中先复现失败，再使用相同流程验证修复。

| 编号 | 问题与复现步骤 | 修复 | 复测 |
| --- | --- | --- | --- |
| 01 | 保存示例，进入记录详情修改备注并保存，再返回工作台：仍显示旧备注，点击“更新备注”可能覆盖复核意见 | 保存复核后同步当前工作台备注；若工作台另有未保存草稿则保留草稿 | 返回后显示新备注，保存按钮显示“已保存”；另行输入的草稿不会被覆盖 |
| 02 | 将当前记录标记为已复核，再从工作台导出 JSON：报告仍为 `reviewed: false` | 当前报告读取已保存的复核状态，保持备注同步 | 读取实际导出的 Blob，核对备注和 `reviewed: true` |
| 03 | 在详情页改备注、取消复核勾选，未保存直接导出 JSON：导出仍是旧内容 | 导出读取当前表单字段，并提示导出与保存是独立操作 | 文件包含当前输入；导出不会暗中修改浏览器记录 |
| 04 | 启动检测后进入历史记录详情填写意见，检测返回时详情弹窗消失、未保存文字丢失 | 异步检测及图片读取完成仅更新工作台，不重建用户正在操作的其他页面 | 延迟模拟检测返回，弹窗与输入保持；返回工作台仍可保存检测结果 |
| 05 | Tab 聚焦检测结果后按 Enter，高亮生效但焦点回到页面根部 | 更新结果后恢复原结果行焦点，增加 `aria-pressed` 选择状态 | 键盘选择后焦点留在该行，可继续 Tab 操作 |

## 可重复运行的浏览器回归

`tests/browser/record-workflow.js` 是 Playwright CLI 可执行的交互检查，失败会抛出异常。仅使用本地测试地址，并会清除这两个测试地址下的禾镜记录，勿在存放重要记录的测试浏览器中运行。

先构建，在两个终端分别运行：

```sh
npm run build
npm run preview -- --port 4176 --strictPort
```

```sh
npm run dev -- --port 5176 --strictPort
```

另开终端，在项目根目录执行：

```sh
npx --yes --package @playwright/cli playwright-cli -s=fieldlens-audit open http://127.0.0.1:4176/
npx --yes --package @playwright/cli playwright-cli -s=fieldlens-audit run-code --filename tests/browser/record-workflow.js
```

覆盖 5 项问题、独立草稿保留、导出不隐式保存、后台检测结果可继续使用，以及浏览器脚本错误检查。模型接口通过显式模拟返回，不依赖模型权重，也不证明模型识别效果。

本轮同时复测图片缩放与标注对齐、PNG/CSV/JSON 下载、保存去重、备注与复核持久化、搜索筛选、分页、单条删除确认、静态检测限制、清除图片、取消等待、图片读取竞争和存储失败提示。页面在 360–2560px 的宽度范围检查；前端 9 项逻辑测试、后端 6 项接口测试和生产构建通过。
