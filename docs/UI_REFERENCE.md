# Element 风格界面统一

检查日期：2026-11-01。范围：禾镜工作台、检测记录管理、运行指南和项目说明。按确认后的范围保留现有业务，不新增登录模块。

## 参考页面

先打开并检查了 Element 2.15.14 官方示例：

- [Color 色彩](https://element.eleme.cn/#/zh-CN/component/color)：主色 `#409EFF`；成功、警告、危险色分别为 `#67C23A`、`#E6A23C`、`#F56C6C`；正文、次级文字、边框使用分层灰色。
- [NavMenu 导航](https://element.eleme.cn/#/zh-CN/component/menu)：分组侧栏、当前项高亮、导航层级。
- [Table 表格](https://element.eleme.cn/#/zh-CN/component/table)：分隔线、斑马纹、悬停反馈与固定操作列。
- [Form 表单](https://element.eleme.cn/#/zh-CN/component/form)：40px 标准输入框、4px 圆角、标签对齐与聚焦状态。

参考组件的视觉与交互规范，样式独立实现。没有复制官网代码或引入组件库。

## 调整

| 使用问题 | 调整 |
| --- | --- |
| 四个导航项没有分组 | 浅色侧栏区分「检测管理」「使用帮助」，面包屑同步显示所属分组 |
| 页面控件颜色、尺寸分散 | 共享配色变量；统一输入框、筛选器、按钮、边框与状态提示 |
| 宽屏右栏过长、图片和结果不便同时查看 | 1600px 及以上为图片、参数、结果三列；中屏两列；平板及手机按宽度堆叠 |
| 记录行较难跟踪 | 斑马纹、悬停背景、统一表头和间距；备注可查看完整提示 |
| 手机上必须滑到最右边才能操作 | 表格区域可横向滚动，详情/导出/删除固定在右侧，补充滑动提示 |
| 手机表单与详情按钮偏小 | 40px 控件、两列导出按钮、详情弹窗固定页头与保存区 |

保留禾镜名称、标志和作物检测内容。当前项目未提供学院名称、校徽或相关素材，因此未虚构学院标识。
