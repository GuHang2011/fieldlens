# 禾镜实用功能设计

日期：2026-11-02。状态：第一批已在 v1.2 实现，包括完整备份恢复、容量保护、样本批次和复查待办。v1.3 已实现逐区域复核、记录数据对比和打印报告，并增加通用 AI 接口；图片持久化、原图对比及批量队列仍为后续设计。详见 [v1.3 说明](INSPECTION_RELEASE.md)。实现范围见 [功能说明](PRACTICAL_RELEASE.md)。

依据当前代码和两轮使用流程检查整理，未进行真实用户访谈。暂按三类使用者设计：采集图片的巡检人员、检查结果的复核人员、用于课程演示的师生。优先完成单人本地使用的闭环，继续使用现有 Element 风格界面。

## 用户任务与优先级

| 优先级 | 用户的问题 | 新功能 | 首版范围 |
| --- | --- | --- | --- |
| P0 | 换电脑、清浏览器后记录怎么找回？第 31 条会挤掉历史记录 | 完整备份与恢复、容量保护 | JSON 批量备份；导入预览、校验、去重；达到容量时不自动删除 |
| P0 | 文件名都是 IMG 开头，不知道是哪块地、哪次采样 | 样本档案与巡检批次 | 样本编号、作物、地块、采集时间、批次；筛选与导出同步支持 |
| P0 | “已看过”不等于处理完，哪些需要重新拍照？ | 复查待办 | 复查原因、计划日期、完成状态；站内到期提醒 |
| P1 | 检测框可能有误，怎样记录人的判断？ | 区域级复核 | 逐框标记待确认、保留、疑似误检，填写理由；保留原始模型结果 |
| P1 | 下次回来只剩数字，怎么对照叶片图片？ | 可选缩略图与两次记录对比 | 明确选择保存缩略图；并排看图和记录；无图时提示补选原图 |
| P1 | 一次拍了几十张，逐张操作太慢 | 批量检测队列 | 本地服务串行处理；失败重试、停止队列、批量导出 |
| P1 | 给老师或同事看，CSV 和 JSON 不够直观 | 巡检报告打印 | 批次概要、样本详情、复核意见、图片来源；浏览器打印为 PDF |

P0 表示下一批优先实现；P1 在基础记录管理稳定后加入。工作量属于相对判断，具体工期需实现时评估。

## 1. 完整备份与恢复

入口放在检测记录页工具栏：「导出备份」「导入备份」。现有 CSV 用于整理，新增 JSON 备份负责完整恢复。

操作流程：选择备份文件 → 显示有效、重复、冲突、无效记录数量 → 选择导入范围 → 确认合并。默认保留已有内容；相同 ID 且内容相同的记录跳过，内容不同的记录要求明确选择，不按时间自动覆盖。导入过程中保留演示或模型来源，来源缺失时拒绝该条记录。

首版继续使用现有存储，并保留 30 条限制以控制改动范围。达到上限时停止新增、保留当前检测结果，提供备份及主动删除入口；不能再自动替换最早记录。导入后超过容量时提示用户减少导入范围。容量升级随第 5 项存储改造推进。

备份包含格式版本、导出时间、记录列表与来源说明，不包含模型权重。兼容现有单条 JSON 报告导入；新版格式采用独立 `schemaVersion`，不以应用版本代替数据格式版本。建议首版文件上限 5 MB，解析前检查大小。

验收：备份后恢复的备注、复核状态、阈值、坐标和来源一致；重复导入不增加记录；坏文件、未知格式、写入失败均不破坏已有数据；第 31 条保存不会丢失第 1 条。

## 2. 样本档案与巡检批次

工作台增加可折叠的「样本信息」，使用标准表单：

| 字段 | 行为 |
| --- | --- |
| 样本编号 | 默认生成，可修改；显示给用户的编号与内部唯一 ID 分开 |
| 作物 | 可输入或选择最近使用项，不推断图片中的作物 |
| 地块 / 温室 | 可输入常用名称，不要求定位权限 |
| 采集时间 | 默认为录入时间并注明来源；与检测时间分别保存 |
| 巡检批次 | 创建或选择，例如“11 月 2 日 A 区巡检” |
| 备注 | 继续使用当前备注，不增加重复填写栏 |

记录列表优先显示样本编号、地块、时间、来源、复核状态；完整属性放详情。增加日期范围、地块、批次筛选，CSV 和报告带上对应字段。手机筛选区保留搜索入口，其他条件折叠。

验收：同名图片不会合并为同一样本；两个批次可有相同样本编号；日期筛选按用户本地日期边界处理；旧记录显示“未填写”，不被丢弃；修改地块不改变模型检测结果。

## 3. 复查待办

记录详情增加「安排复查」，填写原因、计划日期和可选说明。原因可选：图片不清晰、需要补拍、结果存疑、观察变化、其他。

状态采用「待复查 / 已完成 / 已取消」，独立于已有“已人工查看”。到期未完成属于计算出的提示状态，不需要用户手工维护。记录页提供「今日待办」「已到期」快捷筛选。首页只展示真实未完成数量，点击进入对应列表。

复查完成时可关联新检测记录，并填写处理说明；取消时保留原计划及取消状态。首版提醒仅在打开站点时计算，不承诺浏览器关闭后的推送。离开有未保存改动的复查表单时提醒用户。

验收：查看记录不会自动完成待办；完成后不再计入待办；本地午夜后状态正确更新；无日期任务显示“未安排日期”；删除关联记录前说明会影响哪个待办并要求确认。

## 4. 区域级人工复核

点击检测结果行或框打开对应区域，提供「待确认」「保留」「疑似误检」及说明。人工结论单独保存，通过稳定区域 ID 关联原检测框。

原模型类别、置信度、坐标保持可追溯。界面区分“原始区域数”和“人工保留区域数”；导出同时包含原始结果与人工意见。首版不增加重画框、训练模型或修改原模型类别，避免把复核工具扩展成完整标注平台。

验收：调整显示阈值不会把意见关联到另一检测框；重新推理创建新的结果批次，不继承旧框意见；空结果也能添加整图复查意见；“保留”不显示成确诊结论。

## 5. 缩略图与两次记录对比

保存记录时提供「同时保存缩略图到此浏览器」，默认不勾选。说明空间占用和清理方式，支持单条移除缩略图。建议缩略图长边不超过 960px、目标大小不超过 200 KB；编码后仍超限则继续降采样或提示不保存。

图片和记录迁移到 IndexedDB 后，再提升容量。容量按实际占用及浏览器可用空间管理；达到限制时停止写入并提示整理，不自动清理用户记录。迁移完成并读回验证之前保留旧数据。缩略图备份单独勾选，报告注明缩略图不等同原图。

选择两条记录后「对比」：桌面并排，手机上下排列。展示采集时间、地块、模型、阈值、类别和复核说明，支持原图 / 标注切换。旧记录没有图片时允许重新选择，并使用文件指纹核对；没有指纹的旧记录标记为“用户补选，未验证匹配”。

验收：同名但内容不同的文件不能自动匹配；演示与模型记录有明显来源标记；模型或阈值不同提示不可直接比较；不根据检测框数量生成“病情好转百分比”。

## 6. 批量检测队列

入口位于工作台图片区，建议首版每批最多 20 张，沿用单张 10 MB / 2500 万像素限制。添加后先显示队列和校验结果，由用户点击开始。单张校验失败不阻止其他图片。

本地模式串行调用现有 `/api/detect`，避免同时加载过多图片和推理任务。每项显示等待、处理中、成功、失败、已取消，失败项可单独重试。停止队列会停止后续派发并取消当前等待，明确说明无法强制终止已经开始的服务器计算。

在线静态版提供明确标注的预设演示队列，不对用户上传的图片生成虚假检测结果。刷新后可恢复任务摘要；未上传的本地文件需重新选择，不能显示为继续自动执行。批量结果不自动写入正式记录，由用户选择保存，保存前检查容量。

验收：有失败项时其他任务继续；停止后不发送后续请求；重试不重复创建成功记录；切页不丢进度；批量保存与导出的条数、来源一致。依赖第 1、2 项，扩大记录容量建议先完成第 5 项。

## 7. 巡检报告打印

在记录页选择一个批次或若干记录，点击「生成报告」。先预览再打印，使用浏览器“另存为 PDF”，首版无需安装额外服务。

报告包含：批次和地块、采集时间范围、样本数、人工查看情况、复查待办、逐条检测结果及意见。演示记录单独分组并标明“预设演示”；真实记录保留模型名称与阈值。无图记录明确写“未保存图片”，不补放示例插画。

学院或课程名称作为可选填写项，未填写时不展示；已有禾镜品牌继续使用，不预置未知学院名称。打印页不显示按钮、侧栏和网址以外的操作控件。

验收：A4 分页不裁断检测框和表格标题；长备注可换行；中文完整显示；无图、无结果、混合来源均可生成；报告统计以已选记录为准，不能用预设数字。

## 实现顺序与页面组织

建议分三批：

1. 记录可靠性：备份恢复、停止容量覆盖、样本档案与批次。
2. 复核闭环：复查待办、区域级意见、巡检报告。
3. 提高处理效率：缩略图存储与迁移、前后对比、批量队列。

保持「检测管理 / 使用帮助」导航。首批沿用图像检测和检测记录两个业务页面；待办先作为记录页快捷筛选，批次先作为筛选条件。避免每增加一个功能就新增一个一级菜单。

共用验收要求：360、390、768、1440、1920、2560px 下无页面横向溢出；表格可在自身区域滚动；异步检测不关闭编辑表单；保存失败保留用户输入；旧版记录迁移后复核信息不丢失；键盘可完成导入、筛选、保存和导出。

这份方案同时保留已实施需求和后续开发范围。上线介绍只能列入已实现并通过验证的能力，真实模型效果仍需使用授权权重与数据单独评估。
