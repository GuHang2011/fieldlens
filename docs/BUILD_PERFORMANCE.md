# 构建速度与包体积：基线和优化记录

日期：2026-11-04。基线提交：`69032427a23e4acf57f37f15adedb0c403858688`。

本轮保持界面、业务行为、浏览器目标和现有测试不变。最终生产改动仅涉及 `vite.config.js`、`src/features.css`、`src/inspection.css`；另外提供测量脚本与本记录。没有改动业务 JavaScript、依赖版本、构建/测试命令或测试文件。

## 测量方法

- Windows，Node v25.2.1，npm 11.6.2，Vite 8.3.5，Python 3.12.10。
- 先运行 `npm test`，再串行运行 7 次 `npm run build`；记录完整命令墙钟耗时与 Vite 输出的构建阶段耗时，分别取中位数。既有依赖已安装，不包含下载及 `npm ci` 时间。
- 字节数来自 `dist/` 实际文件；gzip 为 Python 标准库逐文件 `compresslevel=9, mtime=0` 后求和，包含 HTML、JS、CSS、两个 SVG。它是固定压缩口径，不等同于 CDN 的实际传输量，也不与 Vite 默认 gzip 摘要混用。
- 每一项实施后执行同样命令。原始计时、每个产物的大小与 SHA-256 见 [测量数据](build-performance.json)。
- 最后增加两次预热和 8 组交替 AB/BA 构建，减少测试先后和缓存的影响。交替测量时停止开发服务器；两种版本使用同一目录与依赖。

复现当前版本：

```bash
npm ci
python scripts/benchmark_build.py --label current --runs 7
```

脚本不改源文件，将日志与 JSON 写入已忽略的 `output/build-performance/`；构建会照常更新 `dist/`。它仅用于开发测量，正常构建不依赖 Python。原始基线可在独立检出的上述提交中使用同一脚本测量。

## 按收益 / 风险排序的候选项

| 顺序 | 候选 | 预期收益与风险 | 决定 |
| --- | --- | --- | --- |
| 1 | `vite build --configLoader native` | 配置是简单 JS，可能省掉配置打包；风险低，但需有稳定收益才值得改变构建方式 | 实测无稳定收益，撤回 |
| 2 | 关闭未使用的 modulepreload polyfill | 单入口、无动态导入及预加载链接，补丁没有需要处理的资源；收益小且确定，当前构建图风险低 | 保留 |
| 3 | 删除无对应 DOM 的旧 CSS | 删除确认无引用的规则，小幅减包；避免涉及层叠、媒体查询合并等高风险变动 | 保留 |
| 4 | 页面懒加载、切换压缩器、大范围合并样式 | 可能扩大减包幅度，但改变加载时序、缓存或样式层叠，当前约 119 kB 总产物下收益有限 | 不实施 |

## 逐项实施与前后对比

| 阶段 | 7 次命令总耗时中位数 | Vite 阶段中位数 | dist 总字节 | 逐文件 gzip 合计 | 现有单元测试 |
| --- | ---: | ---: | ---: | ---: | --- |
| 基线 | 541.32 ms | 43 ms | 118,983 B | 34,582 B | 25/25 |
| 1. native 配置加载实验 | 551.62 ms | 50 ms | 118,983 B | 34,582 B | 25/25 |
| 2. 撤回实验 1，移除预加载补丁 | 498.91 ms | 39 ms | 118,313 B | 34,312 B | 25/25 |
| 3. 在实验 2 上移除旧 CSS | 598.96 ms | 50 ms | 117,920 B | 34,251 B | 25/25 |

这些分阶段计时存在运行环境波动，不能把任意两个阶段直接解释为因果提速或退化。体积结果可重复且不依赖计时。

**1. 配置加载实验已撤回。** 产物路径与全部 SHA-256 一致，未测出足以保留的新收益。`package.json` 和锁文件最终均无差异，因此也不引入新的配置加载兼容性要求。

**2. 预加载补丁。** JS 从 72,316 B 降到 71,646 B，减少 670 B；JS gzip 从 24,098 B 降到 23,829 B，减少 269 B。优化后的 JS 与基线去掉开头 670 字节后的内容逐字节一致，应用代码未改变。HTML 仅引用新的资源哈希；HTML gzip 另减少 1 B。

静态与 `VITE_ENABLE_API=true` 生产构建均只有一个 JS 文件，无 `import()` 和 `modulepreload` 链接。保留 Vite 的其他预加载默认行为，仅设置 `polyfill: false`。若未来引入动态导入、多入口或预加载链接，应重新评估或移除此配置，以保留旧浏览器的预加载回退能力。

**3. 旧样式。** CSS 从 42,677 B 降到 42,284 B，减少 393 B；CSS gzip 从 8,623 B 降到 8,562 B，减少 61 B。只移除以下三组规则及其选择器引用：

- `.detail-meta`：详情分区改版后已无该 class。
- `.inspection-actions`：记录页操作区已改为页头和列表工具栏。
- `.page-heading:has(#export-records)`：CSV 按钮现在位于 `.history-section-heading`，不再位于 `.page-heading` 中。

保留同组的 `.ai-actions`、`.ai-presets`、`.record-note` 等仍使用的选择器。没有进行自动清除 CSS、样式重排或主题改造。

## 最终收益与验证

| 指标 | 基线 | 最终 | 变化 |
| --- | ---: | ---: | ---: |
| dist 总大小 | 118,983 B | 117,920 B | −1,063 B（−0.89%） |
| gzip 合计 | 34,582 B | 34,251 B | −331 B（−0.96%） |
| 交替测量：总耗时中位数 | 585.16 ms | 567.79 ms | −17.37 ms（约 −3%，未认定为稳定提速） |

此次确定收益是小幅减包。构建本身已在几十毫秒量级，命令总耗时主要位于该阶段之外；目前没有足够证据声称显著提升构建速度。
