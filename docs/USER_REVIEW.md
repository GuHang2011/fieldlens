# 用户问题与逐项修复

版本：1.1.0。检查日期：2026-11-01（Asia/Shanghai）。

后续跨页面回归发现并修复的 5 项问题见 [第二轮测试与修复](REGRESSION_REVIEW.md)，附可重复运行的浏览器检查脚本。

保持 Element 风格，从首次访问、图片复核、报告交付和记录管理几个实际使用场景检查。

| 用户角度的问题 | 修复 / 新增功能 | 验证方法 |
| --- | --- | --- |
| 在线版点击“开始检测”才知道不能用 | 顶部说明演示范围；静态模式禁用真实检测按钮，提供运行指南；默认操作可直接加载示例 | 浏览器检查上传后按钮不可点击，且不发起推理请求 |
| 小区域看不清，也不知道图片尺寸 | 50%–300% 相对缩放、适应窗口、图片尺寸、原图/标注切换 | 检查缩放后的图像与 SVG 边界一致 |
| 只能下载 JSON，同事看不方便 | 导出标注 PNG、记录 CSV、JSON；标注图保留来源提示，CSV 支持筛选结果 | 下载文件检查格式、尺寸、记录范围、UTF-8 和公式转义 |
| 连续保存生成重复记录 | 使用检测批次与阈值构成稳定记录 ID；已保存按钮禁用，修改备注更新原记录 | 连续操作后记录数仍为 1，备注更新 |
| 记录多时找不到目标 | 图片名/类别/备注搜索，来源和复核状态筛选，每页 8 条，空结果与统计 | 用 10 条明确标注的测试记录验证分页、组合筛选与重置 |
| 只能看到汇总数字，没法复核 | 详情展示类别、置信度、归一化坐标、图片尺寸；备注与已查看状态持久化 | 修改、刷新后检查内容与状态 |
| 只想删除一条却只能清空 | 单条删除与确认；保留单独的清空全部操作 | 取消确认不删除，确认后只删除目标记录 |
| 选错图片或等待太久不知怎么办 | 清除图片、取消等待；图片读取序号阻止旧异步结果覆盖新选择 | 清除后预览为空，取消后结果不可保存；检查迟到的图片解码结果 |
| 浏览器中有一条坏记录，其他记录也丢了 | 逐条校验和跳过坏记录，兼容旧记录字段，按 ID 去重 | 混合 null、无效日期、旧记录和重复项的单元测试 |
| 从个人展示站找不到项目 | 首页精选项目卡片、技术目录、截图放大、双语介绍和独立案例页 | 检查直接入口、搜索、语言切换、移动端布局和链接 |

## 操作边界

- 在线示例使用合成插画和预设检测框，不代表模型结果；PNG、CSV、JSON 均保留来源说明。
- 记录最多 30 条，只保存文件名、时间、结果、尺寸、备注及复核状态，不保存原图。新增第 31 条时提示最早记录被替换；可提前导出。
- “已复核”仅表示人工查看，并非病害确诊。
- 取消等待会中止浏览器请求和结果更新，不会强制终止服务器上已经开始的推理计算。
- 没有加入视频、批量推理、账号同步或未经授权的权重。真实模型精度仍待在授权数据上验证。

## 验证范围

前端 9 项逻辑测试；后端 6 项既有接口测试；浏览器检查缩放、三种导出、去重、备注、复核、搜索、筛选、分页、删除、取消与四个页面的 360/390/768/1440 宽度。真实模型成功响应的界面集成使用明确模拟的 API 响应，不作为模型性能证据。
